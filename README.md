📅 Randevu Sistemi — Çoklu Hizmet Randevu ve Yönetim Platformu

Hizmet sağlayıcıları için çakışma kontrollü randevu alma, müşteri yorum sistemi ve web tabanlı randevu yönetim uygulamasını barındıran ayrıntılı bir yönetici panel.

🎯 Proje Amacı

Farklı hizmet kategorilerinde (örn. pilates, kuaför vb. herhangi bir hizmet sağlayıcısı) randevu almayı, yönlendirmeyi ve müşteri geri bildirimlerini tek bir platformda toplamayı amaçlayan bir sistem. Hem müşteri hem yönetici tarafı için ayrı bölümler içerir.

✨ Özellikler

Müşteri Tarafı

🗂️ Hizmet kategorilerini gösterme
📝 Uzman, tarih ve saat alabilirsiniz randevu oluşturma
🔍 İsimle randevu sorgulama (girişsiz, gizlilik gizlilik sorgulama sistemi)
⭐ Tamamlanan randevular için puan ve yorum bırakma
✅ Randevu iptal etme

Yönetici Paneli

🔐 Şifreli yönetici girişi
📊 Chart.js ile hizmet satış grafiği ve özet istatistikler (toplam randevu, tahmin ciro, aktif hizmet sayıları)
⚙️ Yeni hizmet / uzman ekleme, mevcut hizmetleri silme
📅 Tüm randevuları görüntüleme, bilgilerin güncellenmesi (bekliyor/tamamlandı), silme
💬 Müşteri yorumlarını görüntüleme ve moderasyon (silme)
🛠️ Kullanılan Teknolojiler
Arka uç: Python (Flask), Jinja2 şablon motoru
Ön uç: HTML, CSS, Saf JavaScript
Görselleştirme: Chart.js
Barındırma: Firebase Hosting (yapılandırma dosyası dahil)
🚀 Kurulum
git clone https://github.com/eliffaytekinn/randevu-sistemi.git
cd randevu-sistemi
pip install flask
python app.py
